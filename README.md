### 👨‍💻 Về bản thân tôi (About Me)

- 🔭 **Định hướng phát triển:** Trở thành kỹ sư **IoT & Embedded Systems / Backend Developer** với tư duy bảo mật (**Cybersecurity**) xuyên suốt từ tầng vi điều khiển phần cứng tới máy chủ dịch vụ.
- ⚡ **Thế mạnh kỹ thuật:** 
  - Lập trình Firmware vi điều khiển (**C/C++, ESP32, FreeRTOS, ESP-IDF**).
  - Xây dựng hệ thống REST API hiệu năng cao (**Node.js, TypeScript, Fastify, NestJS**).
  - Quản trị cơ sở dữ liệu quan hệ và phi quan hệ (**PostgreSQL, MongoDB, MySQL, SQLite**).
  - Giao thức mạng IoT công nghiệp (**MQTT/MQTTS, HTTP/REST, WebSockets**).
  - Nghiên cứu bảo mật hệ thống: Phân quyền RBAC, mã hóa dữ liệu, xác thực thiết bị và phát hiện truy cập bất thường (**Anomaly Detection**).
- 🎯 **Mục tiêu 2026 - 2027:** Hoàn thiện bộ 3 đồ án kỹ thuật chuyên sâu, xây dựng portfolio chuẩn mực và sẵn sàng cho các vị trí *Junior / Fresher IoT Embedded Engineer & Backend Developer*.
